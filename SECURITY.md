# Security Policy

## Supported Versions

We currently support and actively patch the following versions:

| Version | Supported |
| ------- | --------- |
| 0.1.0-alpha | :white_check_mark: |

## Reporting a Vulnerability

**Please do not open public GitHub issues for security vulnerabilities.**

If you discover a security vulnerability in this project, please report it privately via email to:

`security-report@example.invalid`

Please include the following details in your report:
- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue, including any relevant code snippets or payloads.
- Any potential mitigations or patches you have identified.

### Response Time Expectations

Our team takes security seriously. You can expect:
- An initial acknowledgment of your report within 48 hours.
- A detailed update or patch timeline within 7 days.
- A public security advisory (if applicable) once a fix is released.
